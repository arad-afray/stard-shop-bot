# 🛍 ربات فروشگاهی تلگرام متصل به Stard Market — نسخه 2.0.0

ربات کامل فروش **استارز**، **پریمیوم**، **گیفت استارزی**، **بوست کانال/گروه** و **ریکشن استارزی** تلگرام. قیمت‌ها و سفارش‌ها مستقیم به [Stard API](https://stard-market.ir/docs) وصل‌اند. مالک ربات از پنل مدیریت درصد سود خودش را روی قیمت API می‌گذارد و سفارش‌ها **خودکار** ثبت و انجام می‌شوند.

> 🎓 با کلید `sk_test_` بدون پول واقعی همه‌چیز را امتحان کنید. تغییرات این نسخه: **[CHANGELOG.md](CHANGELOG.md)**

## ✨ امکانات

**برای کاربر**
- 🛍 فروشگاه دسته‌بندی‌شده:
  - ⭐ استارز (تعداد آماده یا دلخواه)
  - 💎 پلن‌های پریمیوم
  - 🎁 گیفت‌ها (صفحه‌بندی‌شده، با پیام روی گیفت)
  - 🚀 **بوست کانال/گروه** (انتخاب مدت و تعداد، تحویل خودکار)
  - ❤️ **ریکشن استارزی** روی پست کانال
- 🎟 **کد تخفیف** در پیش‌فاکتور
- 🎁 **دعوت دوستان**: لینک اختصاصی و پاداش از خرید زیرمجموعه‌ها
- 💹 **قیمت لحظه‌ای** دلار، TON و استارز
- 👤 حساب کاربری با کیف پول داخلی، مجموع خرید و آمار زیرمجموعه
- 💳 شارژ کیف پول با کارت‌به‌کارت و عکس رسید
- 📦 تاریخچه‌ی سفارش‌ها و 🔔 خبر خودکار انجام یا برگشت پول
- 🔢 پشتیبانی از اعداد فارسی و عربی

**در گروه‌ها**
- 💹 با نوشتن «قیمت دلار»، «قیمت تون»، «قیمت استارز» یا «قیمت» (یا `/price`) قیمت لحظه‌ای را جواب می‌دهد. دکمه‌ی به‌روزرسانی و «خرید از ربات» دارد و ضد اسپم است.
- ⚠️ برای دیدن پیام‌های عادی گروه، در [@BotFather](https://t.me/BotFather) بزنید **Bot Settings → Group Privacy → Turn off**، یا ربات را در گروه ادمین کنید.

**پنل مدیریت** (`/admin`)
- 📊 **آمار کامل**: کل، ۲۴ ساعت، ۷ و ۳۰ روز؛ به تفکیک بخش؛ بهترین خریداران؛ سود خالص پس از پاداش‌ها
- 💰 درصد سود پیش‌فرض و جداگانه برای هر بخش؛ 🔢 واحد گرد کردن قیمت
- 🗂 روشن/خاموش کردن هر بخش فروشگاه
- 📣 **جوین اجباری**: چند کانال (عمومی یا خصوصی)، افزودن با یوزرنیم، آیدی یا پیام فورواردی
- 🎟 **کد تخفیف**: درصد و سقف استفاده؛ هر کاربر یک بار؛ تخفیف هیچ‌وقت قیمت را زیر قیمت خرید نمی‌برد
- 🎁 **زیرمجموعه‌گیری**: درصد پاداش؛ پاداش هیچ‌وقت از سود همان سفارش بیشتر نمی‌شود
- 🧾 **سفارش‌ها**: اخیر، باز، دستی منتظر، جستجو با شماره. کارت سفارش دکمه‌های «استعلام از Stard»، «انجام شد» و «لغو و برگشت پول» دارد
- 👥 **کاربر**: جستجو، افزایش یا کاهش موجودی، مسدودسازی، سفارش‌ها، تراکنش‌ها، پیام مستقیم
- 💳 تأیید یا رد شارژها؛ دو مدیر نمی‌توانند یک شارژ را دو بار تأیید کنند
- 🏦 موجودی کیف پول Stard، وضعیت سرویس‌های Stard و تراکنش‌های اخیر API
- 📢 پیام همگانی (هر نوع پیام) با پیش‌نمایش، تأیید و گزارش پیشرفت
- 🛠 تنظیمات: کارت، صاحب کارت، حداقل شارژ، متن پشتیبانی، متن خوش‌آمد، **کانال گزارش سفارش‌ها**، واحد گرد کردن
- 💾 **پشتیبان** پایگاه داده با یک دکمه (حتی وقتی ربات روشن است)
- 👮 **مدیرهای اضافه** (فقط مالک از `.env`): مدیرها به کل پنل دسترسی دارند
- 🔴/🟢 باز و بسته کردن فروشگاه؛ 🧪 شبیه‌سازی سفارش در test

**قابلیت اطمینان**
- 🔒 کسر موجودی **اتمیک** است؛ دو خرید هم‌زمان نمی‌توانند موجودی را منفی کنند
- ♻️ **Idempotency-Key** روی هر سفارش و بوست؛ قطعی شبکه دوبار خرید نمی‌سازد
- 🧾 **quote_id** قیمت را قفل می‌کند؛ اگر قیمت بالا برود، سفارش بدون کسر پول رد می‌شود
- ↩️ برگشت پول فقط یک بار؛ سفارش انجام‌شده هرگز برگشت نمی‌خورد؛ کد تخفیف مصرف‌شده آزاد می‌شود
- 🛡 لغو دستی مدیر اول در Stard انجام می‌شود تا هم محصول نرسد و هم پول برنگردد
- 📒 دفتر کل (ledger): هر تومان قابل ردیابی است
- ⚡️ کش ۶۰ ثانیه‌ای کاتالوگ و نرخ‌ها، و کش تنظیمات در حافظه؛ پیش‌قیمت سفارش هیچ‌وقت کش نمی‌شود
- 🔁 تلاش دوباره روی 429، 5xx و قطعی شبکه با فاصله‌ی افزایشی
- 🧯 هر خطای پیش‌بینی‌نشده لاگ می‌شود و ربات از کار نمی‌افتد
- ⬆️ ارتقای خودکار پایگاه داده‌ی نسخه‌ی ۱ (اطلاعات قبلی حفظ می‌شود)

## ❤️ درباره‌ی ریکشن استارزی

Stard API برای ریکشن استارزی endpoint ندارد. بنابراین این سفارش **دستی** است:
1. کاربر تعداد و لینک پست را می‌دهد. قیمت از نرخ لحظه‌ای استارز در Stard به‌علاوه‌ی سود بخش «ریکشن» محاسبه و از کیف پول کسر می‌شود.
2. برای همه‌ی مدیرها پیام با دو دکمه‌ی **✅ انجام شد** و **↩️ رد و برگشت پول** می‌آید.
3. مدیر ریکشن را می‌زند و دکمه را فشار می‌دهد. ربات به کاربر خبر می‌دهد.

اگر نمی‌خواهید این بخش را بفروشید، از **🗂 بخش‌های فروشگاه** خاموشش کنید.

## 🚀 راه‌اندازی

### ۱. پیش‌نیازها
- یک ربات از [@BotFather](https://t.me/BotFather) و توکن آن
- آیدی عددی خودتان (از [@userinfobot](https://t.me/userinfobot))
- کلید API از [داشبورد Stard](https://stard-market.ir/developers/dashboard). برای شروع کلید `sk_test_` بسازید.

### ۲. تنظیم

```bash
git clone https://github.com/arad-afray/stard-shop-bot.git
cd stard-shop-bot
cp .env.example .env
# فایل .env را باز کنید و BOT_TOKEN و ADMIN_IDS و STARD_API_KEY را پر کنید
```

### ۳. اجرا

**با Docker (پیشنهادی):**
```bash
docker compose up -d --build
docker compose logs -f
```

**بدون Docker** (Python 3.11 به بالا):
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

### ۴. اولین تنظیمات در ربات
1. `/start` را بزنید و بعد **⚙️ پنل مدیریت** را باز کنید.
2. در **🛠 تنظیمات**، شماره کارت و نام صاحب کارت را وارد کنید (بدون این دو، شارژ کیف پول غیرفعال است).
3. در **💰 درصد سود**، سود دلخواه را تنظیم کنید.
4. در **🏦 کیف پول Stard**، اتصال و موجودی API را بررسی کنید.

## ⚙️ متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `BOT_TOKEN` | توکن ربات | الزامی |
| `ADMIN_IDS` | آیدی عددی مدیرها، با کاما جدا | — |
| `STARD_API_KEY` | `sk_test_…` یا `sk_live_…` | الزامی |
| `STARD_BASE_URL` | آدرس API | `https://stard-market.ir/api/v1` |
| `STARD_PAY_CURRENCY` | `IRT` یا `TON` برای پرداخت از کیف پول API | پیش‌فرض داشبورد |
| `DATABASE_PATH` | مسیر فایل SQLite | `data/shop.db` |
| `DEFAULT_PROFIT_PERCENT` | سود اولیه (از پنل قابل تغییر است) | `10` |
| `POLL_INTERVAL_SECONDS` | فاصله‌ی پیگیری سفارش‌ها | `20` |
| `LOG_LEVEL` | سطح لاگ | `INFO` |

## 🧭 جریان سفارش

```
کاربر محصول را انتخاب می‌کند
   └─► POST /orders/quote       قیمت Stard + quote_id (قفل ۲ دقیقه‌ای)
   └─► قیمت فروش = قیمت × (۱ + سود٪)
کاربر گیرنده را وارد و تأیید می‌کند
   └─► کسر موجودی + ساخت سفارش  (یک تراکنش)
   └─► POST /orders             با Idempotency-Key: bot-<id>
worker هر ۲۰ ثانیه
   └─► GET /orders/{id}  (بوست: GET /boosts/orders/{id})
         completed                  → «تحویل شد» به کاربر
         failed/cancelled/refunded  → برگشت پول + اطلاع
```

توضیح کامل API، خطاها و دلیل هر تصمیم: **[docs/API.md](docs/API.md)**

خلاصه‌ی همه‌ی دستورها (نصب، اجرا، به‌روزرسانی): **[COMMANDS.txt](COMMANDS.txt)**

## 🧪 تست‌ها

```bash
pip install -r requirements-dev.txt
pytest -q
```

تست‌ها بدون اینترنت و با یک شبیه‌ساز Stard API (`tests/fake_stard.py`) اجرا می‌شوند (۵۱ تست). این موارد را پوشش می‌دهند: محاسبه‌ی سود و تخفیف، کسر هم‌زمان موجودی، رقابت روی کد تخفیف، برگشت پول فقط یک بار، تغییر قیمت، گم شدن پاسخ شبکه بدون دوبار خرید، بوست، ریکشن دستی، پاداش معرف، جوین اجباری، قیمت در گروه، ارتقای پایگاه داده‌ی نسخه‌ی ۱، پشتیبان‌گیری، و همه‌ی صفحه‌های پنل مدیریت از طریق Dispatcher واقعی aiogram. هر خطای مدیریت‌نشده در هندلرها تست را رد می‌کند.

## 🔴 رفتن به live

1. حساب تلگرام Stard را در داشبورد وصل کنید.
2. کیف پول Stard را شارژ کنید.
3. کلید `sk_live_` بسازید و در `.env` جایگزین کنید.
4. ربات را ری‌استارت کنید. در **🏦 کیف پول Stard** باید «live» نمایش داده شود.

> ⚠️ در live، موجودی کیف پول Stard باید همیشه از مجموع سفارش‌های در جریان بیشتر باشد. اگر کم باشد، سفارش‌ها با `insufficient_funds` رد می‌شوند و پول کاربر برمی‌گردد.

## 🛡 نکات امنیتی
- فایل `.env` را هیچ‌وقت در گیت نگذارید (در `.gitignore` هست).
- کلید API فقط روی سرور می‌ماند و هیچ‌وقت به کاربر نشان داده نمی‌شود.
- از پوشه‌ی `data/` (پایگاه داده) به‌طور منظم پشتیبان بگیرید.
