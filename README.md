# 🛍 ربات فروشگاهی تلگرام متصل به Stard Market

ربات کامل فروش **استارز تلگرام**، **تلگرام پریمیوم** و **گیفت استارزی**. قیمت‌ها و سفارش‌ها مستقیم به [Stard API](https://stard-market.ir/docs) وصل‌اند. مالک ربات از پنل مدیریت درصد سود خودش را روی قیمت API می‌گذارد و سفارش‌ها **خودکار** ثبت و انجام می‌شوند.

> 🎓 این پروژه برای **آموزش** و یک **ربات تست کامل** ساخته شده است. با کلید `sk_test_` بدون پول واقعی همه‌چیز را امتحان کنید.

## ✨ امکانات

**برای کاربر**
- 🛍 فروشگاه دسته‌بندی‌شده: استارز (تعداد آماده یا دلخواه)، پلن‌های پریمیوم، گیفت‌ها (صفحه‌بندی‌شده)
- 👤 حساب کاربری با کیف پول داخلی
- 💳 شارژ کیف پول با کارت‌به‌کارت و ارسال عکس رسید
- 🧾 پیش‌فاکتور قبل از پرداخت؛ دکمه‌ی «برای خودم» برای انتخاب سریع گیرنده
- 📦 تاریخچه‌ی سفارش‌ها با وضعیت لحظه‌ای
- 🔔 خبر دادن خودکار وقتی سفارش انجام یا ناموفق شد
- 🔢 پشتیبانی از اعداد فارسی و عربی در ورودی‌ها

**برای مالک (پنل مدیریت)**
- 💰 **درصد سود**: یک درصد پیش‌فرض، به‌علاوه‌ی درصد جداگانه برای هر دسته
- 📊 آمار: کاربران، فروش کل، **سود خالص**، سفارش‌های در جریان و برگشتی
- 💳 تأیید یا رد شارژها با یک دکمه (دو مدیر نمی‌توانند یک شارژ را دو بار تأیید کنند)
- 👥 مدیریت کاربر: جستجو با آیدی یا یوزرنیم، افزایش یا کاهش موجودی، مسدود کردن
- 🧾 سفارش‌های اخیر با قیمت خرید، قیمت فروش و دلیل خطا
- 🏦 موجودی کیف پول Stard API و محیط فعال (test یا live)
- 📢 پیام همگانی (متن، عکس، ویدیو…) با رعایت محدودیت تلگرام
- 🛠 تنظیمات: شماره کارت، نام صاحب کارت، حداقل شارژ، متن پشتیبانی
- 🔴/🟢 باز و بسته کردن فروشگاه
- 🧪 شبیه‌سازی نتیجه‌ی سفارش (فقط در محیط test)

**قابلیت اطمینان**
- 🔒 کسر موجودی **اتمیک** است؛ دو خرید هم‌زمان نمی‌توانند موجودی را منفی کنند
- ♻️ **Idempotency-Key** روی هر سفارش؛ اگر شبکه قطع شود، دوبار خرید پیش نمی‌آید
- 🧾 **quote_id** قیمت را قفل می‌کند؛ اگر قیمت بالا برود، سفارش بدون کسر پول رد می‌شود
- ↩️ برگشت خودکار پول سفارش ناموفق، **فقط یک بار**
- 📒 دفتر کل (ledger): هر تومان واریز و برداشت قابل ردیابی است
- 🔁 تلاش دوباره روی 429، 5xx و قطعی شبکه با فاصله‌ی افزایشی

## 🚀 راه‌اندازی

### ۱. پیش‌نیازها
- یک ربات از [@BotFather](https://t.me/BotFather) و توکن آن
- آیدی عددی خودتان (از [@userinfobot](https://t.me/userinfobot))
- کلید API از [داشبورد Stard](https://stard-market.ir/developers/dashboard). برای شروع کلید `sk_test_` بسازید.

### ۲. تنظیم

```bash
git clone https://github.com/arad-afray/stard-shop-bot.git
cd stard-shop-bot
cp .env.example .env
# فایل .env را باز کنید و BOT_TOKEN و ADMIN_IDS و STARD_API_KEY را پر کنید
```

### ۳. اجرا

**با Docker (پیشنهادی):**
```bash
docker compose up -d --build
docker compose logs -f
```

**بدون Docker** (Python 3.11 به بالا):
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

### ۴. اولین تنظیمات در ربات
1. `/start` را بزنید و بعد **⚙️ پنل مدیریت** را باز کنید.
2. در **🛠 تنظیمات**، شماره کارت و نام صاحب کارت را وارد کنید (بدون این دو، شارژ کیف پول غیرفعال است).
3. در **💰 درصد سود**، سود دلخواه را تنظیم کنید.
4. در **🏦 کیف پول Stard**، اتصال و موجودی API را بررسی کنید.

## ⚙️ متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `BOT_TOKEN` | توکن ربات | الزامی |
| `ADMIN_IDS` | آیدی عددی مدیرها، با کاما جدا | — |
| `STARD_API_KEY` | `sk_test_…` یا `sk_live_…` | الزامی |
| `STARD_BASE_URL` | آدرس API | `https://stard-market.ir/api/v1` |
| `STARD_PAY_CURRENCY` | `IRT` یا `TON` برای پرداخت از کیف پول API | پیش‌فرض داشبورد |
| `DATABASE_PATH` | مسیر فایل SQLite | `data/shop.db` |
| `DEFAULT_PROFIT_PERCENT` | سود اولیه (از پنل قابل تغییر است) | `10` |
| `POLL_INTERVAL_SECONDS` | فاصله‌ی پیگیری سفارش‌ها | `20` |
| `LOG_LEVEL` | سطح لاگ | `INFO` |

## 🧭 جریان سفارش

```
کاربر محصول را انتخاب می‌کند
   └─► POST /orders/quote       قیمت Stard + quote_id (قفل ۲ دقیقه‌ای)
   └─► قیمت فروش = قیمت × (۱ + سود٪)
کاربر گیرنده را وارد و تأیید می‌کند
   └─► کسر موجودی + ساخت سفارش  (یک تراکنش)
   └─► POST /orders             با Idempotency-Key: bot-<id>
worker هر ۲۰ ثانیه
   └─► GET /orders/{id}
         completed                  → «تحویل شد» به کاربر
         failed/cancelled/refunded  → برگشت پول + اطلاع
```

توضیح کامل API، خطاها و دلیل هر تصمیم: **[docs/API.md](docs/API.md)**

خلاصه‌ی همه‌ی دستورها (نصب، اجرا، به‌روزرسانی): **[COMMANDS.txt](COMMANDS.txt)**

## 🧪 تست‌ها

```bash
pip install -r requirements-dev.txt
pytest -q
```

تست‌ها بدون اینترنت و با یک شبیه‌ساز Stard API (`tests/fake_stard.py`) اجرا می‌شوند. این موارد را پوشش می‌دهند: محاسبه‌ی سود، کسر هم‌زمان موجودی، برگشت پول فقط یک بار، تغییر قیمت، گم شدن پاسخ شبکه بدون دوبار خرید، و فرایند کامل خرید، شارژ و پنل مدیریت از طریق Dispatcher واقعی aiogram.

## 🔴 رفتن به live

1. حساب تلگرام Stard را در داشبورد وصل کنید.
2. کیف پول Stard را شارژ کنید.
3. کلید `sk_live_` بسازید و در `.env` جایگزین کنید.
4. ربات را ری‌استارت کنید. در **🏦 کیف پول Stard** باید «live» نمایش داده شود.

> ⚠️ در live، موجودی کیف پول Stard باید همیشه از مجموع سفارش‌های در جریان بیشتر باشد. اگر کم باشد، سفارش‌ها با `insufficient_funds` رد می‌شوند و پول کاربر برمی‌گردد.

## 🛡 نکات امنیتی
- فایل `.env` را هیچ‌وقت در گیت نگذارید (در `.gitignore` هست).
- کلید API فقط روی سرور می‌ماند و هیچ‌وقت به کاربر نشان داده نمی‌شود.
- از پوشه‌ی `data/` (پایگاه داده) به‌طور منظم پشتیبان بگیرید.
