=====================================================
   دستورات مهم stard-shop-bot نسخه 3 (ویندوز / PowerShell)
=====================================================

همه‌ی دستورها را در PowerShell داخل پوشه‌ی پروژه بزنید:
  cd "C:\Users\arad\Desktop\New folder (3)\stard-shop-bot"
موقع اجرای ربات، VPN باید روشن باشد (تلگرام در ایران فیلتر است).


-----------------------------------------------------
۱) به‌روزرسانی از نسخه‌ی ۲ به ۳ (فقط یک بار)
-----------------------------------------------------

  ۱. ربات را با Ctrl + C خاموش کنید
  ۲. فایل update.ps1 را از گیت‌هاب دانلود و در پوشه‌ی پروژه بگذارید:
       curl.exe -L -o update.ps1 https://raw.githubusercontent.com/arad-afray/stard-shop-bot/claude/starship-bot-github-access-qggts8/update.ps1
  ۳. اجرا:
       powershell -ExecutionPolicy Bypass -File .\update.ps1

  کارهایی که انجام می‌دهد: پشتیبان از data و .env ← دریافت کد ← نصب کتابخانه‌ها ← ارتقای پایگاه داده
  ← بررسی سلامت. اگر خطا بدهد، همه‌چیز خودکار به حالت قبل برمی‌گردد. اطلاعات کاربرها و موجودی‌ها حفظ می‌شود.


-----------------------------------------------------
۲) اجرای ربات (با Restart خودکار)
-----------------------------------------------------

  powershell -ExecutionPolicy Bypass -File .\run.ps1

  اگر ربات کرش کند خودکار دوباره روشن می‌شود. بعد از به‌روزرسانی از داخل پنل هم خودکار Restart می‌شود.
  خاموش کردن: Ctrl + C
  (روش قدیمی «python -m bot» هم کار می‌کند، ولی Restart خودکار ندارد.)


-----------------------------------------------------
۳) به‌روزرسانی‌های بعدی
-----------------------------------------------------

  راه آسان: در ربات ← پنل مدیریت ← 🛠 سیستم ← 🔄 بررسی آپدیت پروژه ← 🚀 آپدیت
  یا دستی:
    powershell -ExecutionPolicy Bypass -File .\update.ps1


-----------------------------------------------------
۴) پشتیبان‌گیری
-----------------------------------------------------

  خودکار: هر ۲۴ ساعت در پوشه‌ی backups (قابل تنظیم در .env).
  دستی: پنل ← 🛠 سیستم ← 💾 Backup Manager ← Create Backup (و دکمه‌ی دانلود)
  پوشه‌ی backups و فایل .env را گاهی روی فلش/فضای ابری هم کپی کنید.
  فایل .env را به هیچ‌کس ندهید (توکن و کلید API در آن است).


-----------------------------------------------------
۵) دستورهای کمکی
-----------------------------------------------------

  وضعیت پایگاه داده:          python -m bot.migrate --check
  بررسی سلامت کد و پایگاه داده: python -m bot.selfcheck
  اجرای تست‌ها:                python -m pip install -r requirements-dev.txt
                                python -m pytest -q
  لاگ‌ها:                      پوشه‌ی logs (یا پنل ← 🛠 سیستم ← 📜 لاگ‌های سیستم)


-----------------------------------------------------
۶) سرور لینوکس با Docker (PostgreSQL + Redis)
-----------------------------------------------------

  cp .env.example .env && nano .env      (POSTGRES_PASSWORD را هم بگذارید)
  docker compose up -d --build           روشن کردن
  docker compose logs -f bot worker      دیدن لاگ
  docker compose down                    خاموش کردن
  git pull && docker compose up -d --build     به‌روزرسانی
  راهنمای کامل: docs/DEPLOY.md
