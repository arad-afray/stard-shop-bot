=====================================================
   دستورات مهم پروژه‌ی stard-shop-bot (ویندوز / PowerShell)
=====================================================

همه‌ی دستورها را در PowerShell بزنید.
موقع اجرای ربات، VPN باید روشن باشد (تلگرام در ایران فیلتر است).


-----------------------------------------------------
۱) نصب اولیه (فقط یک بار)
-----------------------------------------------------

پیش‌نیازها:
  - Git:     https://git-scm.com/download/win
  - Python:  https://www.python.org/downloads/
             (موقع نصب تیک «Add python.exe to PATH» را بزنید)

دانلود پروژه از گیت‌هاب:
  git clone https://github.com/arad-afray/stard-shop-bot.git

رفتن داخل پوشه‌ی پروژه:
  cd stard-shop-bot

نصب کتابخانه‌ها:
  python -m pip install -r requirements.txt

ساختن فایل تنظیمات:
  copy .env.example .env

باز کردن فایل تنظیمات برای پر کردن:
  notepad .env

  این سه خط را حتماً پر کنید و ذخیره کنید:
    BOT_TOKEN=توکن ربات از @BotFather
    ADMIN_IDS=آیدی عددی شما (از @userinfobot)
    STARD_API_KEY=sk_test_...   (از stard-market.ir/developers/dashboard)


-----------------------------------------------------
۲) اجرای ربات
-----------------------------------------------------

رفتن داخل پوشه‌ی پروژه (هر بار که PowerShell را باز می‌کنید):
  cd "C:\Users\arad\Desktop\New folder (3)\stard-shop-bot"

روشن کردن ربات:
  python -m bot

  اگر در لاگ «Stard API OK» دیدید یعنی اتصال درست است.
  تا وقتی این پنجره باز است ربات کار می‌کند.

خاموش کردن ربات:
  Ctrl + C


-----------------------------------------------------
۳) به‌روزرسانی (وقتی کد در گیت‌هاب عوض شد)
-----------------------------------------------------

  ۱. ربات را با Ctrl + C خاموش کنید
  ۲. cd "C:\Users\arad\Desktop\New folder (3)\stard-shop-bot"
  ۳. git pull
  ۴. python -m pip install -r requirements.txt
  ۵. python -m bot

  فایل .env و پوشه‌ی data با git pull پاک نمی‌شوند.
  فایل‌های کد را خودتان تغییر ندهید، وگرنه git pull خطا می‌دهد.


-----------------------------------------------------
۴) دستورهای کمکی
-----------------------------------------------------

دیدن وضعیت فایل‌ها (آیا چیزی تغییر کرده):
  git status

اگر git pull به خاطر تغییر فایل‌ها خطا داد، برگرداندن کد به نسخه‌ی گیت‌هاب
(تنظیمات .env و اطلاعات data دست نمی‌خورند):
  git checkout -- .
  git pull

اجرای تست‌ها (برای اطمینان از سالم بودن کد):
  python -m pip install -r requirements-dev.txt
  python -m pytest -q

بررسی دستی کلید Stard (در PowerShell):
  curl.exe https://stard-market.ir/api/v1/ping -H "Authorization: Bearer sk_test_..."


-----------------------------------------------------
۵) پشتیبان‌گیری
-----------------------------------------------------

اطلاعات کاربرها، موجودی‌ها و سفارش‌ها در این فایل است:
  data\shop.db

وقتی ربات خاموش است، از پوشه‌ی data یک کپی جای امن نگه دارید.
فایل .env را هم نگه دارید و به هیچ‌کس ندهید (توکن و کلید API در آن است).


-----------------------------------------------------
۶) اجرا روی سرور لینوکس با Docker (اختیاری)
-----------------------------------------------------

  git clone https://github.com/arad-afray/stard-shop-bot.git
  cd stard-shop-bot
  cp .env.example .env
  nano .env
  docker compose up -d --build     روشن کردن
  docker compose logs -f           دیدن لاگ
  docker compose down              خاموش کردن
  git pull && docker compose up -d --build     به‌روزرسانی
